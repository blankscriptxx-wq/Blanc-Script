# Media assets

Drop site images/videos here and reference them from `data/` (e.g.
`src: "/media/ibrahim.jpg"`). Filenames map to `/media/<filename>` at runtime.

Founder portraits expected by data/team.ts:
- ibrahim.jpg  → Ibrahim Ali  (tuxedo / red-carpet photo)
- noman.jpg    → Noman Ahmed  (sunglasses photo)
